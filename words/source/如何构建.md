# 如何从源码构建

解压 `waketang-words-src.zip` 后，得到完整源码树（不含 `node_modules`）。

## 环境要求

- Node.js 18 以上（开发时用的是 Node 24）
- pnpm 9 以上（本项目用 pnpm 管理依赖；npm / yarn 理论上也行，但没验证过）

## 构建网页版（就是本站「背单词」栏目跑的那份）

```bash
pnpm install

# 国内网络建议加镜像
#   $env:ELECTRON_MIRROR='https://npmmirror.com/mirrors/electron/'
#   pnpm install --registry=https://registry.npmmirror.com

pnpm build:web      # 产物在 build/ 目录
```

`build:web` 与 `build` 的唯一区别是设了 `REACT_APP_DEPLOY_ENV=web`，
让前端改用 `HashRouter` —— 静态托管下刷新 `/words/#/typing` 才不会 404。

把 `build/` 整个目录的内容复制到网站根目录下的 `words/` 即可。

## 构建 Windows 桌面版（可选）

```bash
pnpm release        # = pnpm build && electron-builder --win --publish never
```

产物在项目外的 `release/` 目录（便携版 exe + NSIS 安装包）。

## 本地开发

```bash
pnpm dev            # 起开发服务器，默认 http://localhost:5173
```

## 目录速览

```
src/
  index.tsx                    入口，路由（桌面版 BrowserRouter / 网页版 HashRouter）
  index.css                    设计 token + 组件层（全站配色、间距、按钮都在这里）
  components/                  共用组件（Header / Setting / WordDetailPanel / Tooltip…）
  pages/
    Today/                     今日计划（首页）
    Recall/                    选词记忆（词卡 + 双向选择题）
    Typing/                    拼写练习
    Gallery-N/                 词库
    Analysis/                  统计
    ErrorBook/                 错词本
  utils/
    srs.ts                     艾宾浩斯调度（纯函数，可单测）
    db/                        Dexie / IndexedDB
public/dicts/                  词库数据（24 本 JSON）
```

## 自测脚本

源码树里带了几个验收脚本（在项目根的 `tools/`）：

```bash
node tools/test-srs.mjs            # 调度器单元测试
node tools/recall-verify.mjs       # 选词记忆 + 先认后拼门禁 端到端（需先 pnpm dev）
node tools/electron-verify.mjs     # 桌面版打包产物验收
```
