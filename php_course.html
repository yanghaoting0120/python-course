    PHP 是运行在服务器端的语言。学习页里的示例可以直接复制，动手运行前请先准备本机 PHP 环境：

    电脑已装 WAMP 或 PHP：把示例文件放进网站目录（如 WAMP 的 www），用 http://localhost 访问运行。
    电脑没有安装 PHP：推荐安装 WAMP（Windows + Apache + MySQL + PHP），或到 php.net 下载官方版本。
